Sesja VS Code
Środowisko wymaga rzeczywistego, zgodnego bootstrap ARM64 z Node i code-server.
Po uruchomieniu hasło jest wyświetlane jednorazowo i nie jest zapisywane w przeglądarce. Po zamknięciu sesji serwer jest zatrzymywany. Rozszerzenia VS Code z natywnymi modułami Linux mogą być niezgodne z Androidem.
