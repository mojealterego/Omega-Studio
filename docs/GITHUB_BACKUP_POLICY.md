# Zasady kopii GitHub

Repozytorium `mojealterego/Omega-Studio`, gałąź `main`. Każdy commit musi zawierać `[skip ci] [skip actions]`; nie uruchamiać płatnych GitHub-hosted Actions. `Digital-Life` pozostaje nienaruszone. Do publicznego repozytorium wolno zapisywać tylko własny kod i materiały z jednoznaczną licencją; archiwa źródeł DroidScript bez ustalonej licencji nie są publikowane. GitHub REST Contents API i Git blobs nie stanowią systemu dystrybucji dużych plików; kopia kodu, artefaktów i oryginalnych źródeł musi być raportowana osobno, z dowodami SHA-256.
